EDUMIND AI — WEBSITE CODE ZIP

HOW TO RUN
1. Extract this ZIP file.
2. Open the edumind_ai_website folder.
3. Double-click index.html to open the website in Chrome or Edge.

INCLUDED
- Responsive student dashboard
- Academic journey and study-plan interaction
- DSA sample assessment and score feedback
- Editable skill scores and career gap table
- Daily plan generator
- Rescue Mode workload checker
- AI insights demo page

IMPORTANT
This is a frontend prototype using HTML, CSS, and JavaScript with sample data.
It does not yet include a real AI model/API, login system, backend, or persistent database.
Those can be added in the next development stage.
